# 生产环境部署检查清单

## 基础设施

- [ ] 使用 PostgreSQL 而非 SQLite
- [ ] 配置数据库连接池 (最小 10 连接)
- [ ] 启用数据库备份 (每日全量 + 每小时增量)
- [ ] 配置防火墙规则 (仅开放 80/443 端口)
- [ ] 启用 TLS/SSL (使用 Let's Encrypt 或商业证书)

## 安全配置

- [ ] 修改默认管理员密码 (至少 16 位随机密码)
- [ ] 禁用 ONTOLOGY_AUTH_DISABLED
- [ ] 配置正确的 CORS 域名 (不要使用 *)
- [ ] 设置强加密密钥 (ONTOLOGY_ENCRYPTION_KEY)
- [ ] 配置 RBAC 权限策略
- [ ] 启用审计日志
- [ ] 定期轮换密钥
