# 文档索引

> ⚠️ **重要：`01`–`04` 是设计文档，部分内容超前于当前实现。**
>
> 它们记录的是设计意图，不是已交付能力的清单。例如
> `02-核心元模型设计.md` 描述了 Event 与 State 作为一等公民，
> 而 schema 中目前没有对应的表。
>
> **判断某项能力是否可用，请以 [README 的能力矩阵](../README.md#能力矩阵)
> 与 [当前限制](../README.md#当前限制) 为准。**
