# Development and CI install. Deliberately not a second list of pins.
#
# The supported versions live in one place -- `pyproject.toml`'s extras -- because two
# lists of the same pins drift, and the drift is invisible: CI passes on versions no
# user ever installs, and the failure surfaces in someone else's environment. Automated
# dependency updates made this concrete, since a bot editing only this file cannot see
# `requires-python` and proposed releases that do not support the floor we promise.
#
# Editable so `pip install -r requirements.txt` gives the same interpreter view the
# tests assume, and so a change to the extras takes effect without re-editing anything.
-e .[all,dev]
